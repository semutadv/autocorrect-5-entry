An autocorrect fail in one line, written for the make.fun bounty
"Funniest Autocorrect Fail". A perfectly normal dinner text, ruined
twice by the keyboard: the chicken is being defused, not defrosted,
and the guests have been asked to bring whine. Several were already
bringing some.

## Running it

`node main.ts` clears the output directory's contents and writes the
text to `/output/entry.txt` as plain UTF-8 text.
